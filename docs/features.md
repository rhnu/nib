## 工作台与当前创作

顶部提供图像生成、导演工具、画廊、资源、词库和设置六个页面。图像生成页左侧编排提示词、预设、图像输入、角色与参考，底部调整生成参数并提交；右侧共用主区查看源图、预览和结果，也可编辑遮罩或角色位置。最近图片位于下方，完整图片历史进入画廊，任务队列从抽屉打开。

工作台自动保留一份当前创作，包括提示词、资源实例、生成参数、参考材料和图像编辑状态，重启后恢复。当前创作无需命名或手动保存；需要命名复用的内容保存为片段或预设。资源原件单独保存。

切页保留当前编辑及各页面的浏览上下文。关闭窗口前，会先处理未保存资源和未应用遮罩，再等待材料操作、当前创作与全局设置写入完成；失败时保留窗口和编辑，并提供重试。

应用统一禁用 WebView 默认右键菜单。文本输入、提示词编辑器、资源条目、目录和图片提供各自的菜单；普通文本输入沿用原生编辑快捷键，提示词编辑保留自身撤销历史。图片菜单提供保存、复制图片、信息查看及适用图像操作。三点菜单、右键与键盘入口共用操作条件，Escape 关闭菜单后焦点返回原位置。

## 资源与提示词

### 片段、预设与实例

资源库左侧管理目录，中间浏览资源，右侧检查器显示所选资源的封面、内容摘要与元数据；可切换网格和详细列表，也可关闭检查器。搜索匹配名称与别名，可按类型、标签、声明的模型范围、目录及子目录筛选，并分页和排序。名称允许重复，引用使用稳定 UUID，移动和改名不改变引用。切换页面保留浏览上下文和未保存修改。资源页专用于原件管理。主提示词、角色提示词的片段入口，以及工作台的预设入口，均打开统一资源选择弹窗，不跳转到管理页。

新建或编辑资源时，可以填写描述、别名、标签、适用模型和所属目录。未选择适用模型表示无限制，模型范围与预设的默认模型设置分别保存。片段提供文本；预设可组合正负提示词中的文本与片段、角色、参考材料及默认设置。原件使用显式保存，未保存内容和保存失败保持可见。

封面可从文件、剪贴板或已有图片选择。保存时复制为资源自有图片，画廊原图之后的修改或删除不影响封面。拖放可移动资源与目录，菜单提供移动和复制；多选后可以批量移动、复制、修改标签与模型范围。删除前显示目录内容和受影响引用；共享标签可以统一改名或移除。

片段标题栏以勾选图标表示启停，上移、下移与移除直接显示在同排。片段引用的操作菜单提供展开与撤销本次覆盖；预设的排序与移除同样位于标题栏。

选择弹窗左侧显示文件夹，右侧默认使用网格，可切换详细列表；支持名称 / 别名搜索、标签、当前模型适用范围与子目录筛选。标题显示插入目标，底栏固定显示分页、当前选择和插入按钮；目录和结果区分别滚动。双击资源或确认选择后，将资源插入原提示词作用域或应用预设列表，并显示包含资源名称的通知；取消保留原编辑状态。

当前创作可添加文本、片段和预设，并调整启停和顺序：

- 编辑引用文字或预设设置时，只覆盖当前实例；撤销覆盖后继续使用原件。
- 展开片段得到独立文本；展开预设保留当时的内容、启停、角色、参考与合并后的设置，并解除资源引用。
- 解析按预设顺序组合内容，再追加当前创作的直接片段；片段以换行分隔，保留 NAI 提示词语法。
- 删除原件不移除已有引用，解析会标明缺失依赖。展开时也需完整取得停用内容，避免以后启用时丢失材料。

“解析”面板可查看最终文本、来源、设置覆盖及缺失或失效的引用，并定位到对应片段、角色或预设实例。实际启用的预设和片段必须适用于最终模型，不兼容时阻止估费和提交；停用内容保留但不阻止当前生成。

### 编辑与词符用量

图像生成页的提示词输入区初始容纳两枚按钮，随内容自动增高。插入的片段引用默认折叠，文本片段默认展开；标题栏可切换折叠，保留一行截断的原文预览及词符统计按钮，隐藏词库按钮。生成页主提示词、角色及预设实例中的片段折叠状态随当前创作自动保存，切页与重启后恢复；同一资源的不同引用分别记录。展开后保留光标、选区和撤销历史，定位错误会展开对应片段并保存该状态。普通文本称为“文本片段”，可复用资源称为“片段”，引用资源时称为“片段引用”。

基础、负面、角色、片段、实例覆盖及只读解析文本共用提示词编辑器，采用内置 Maple Mono CN 等宽字体。高亮与权重分析随实际模型适配括号、数字权重、随机分支、混合提示词和角色分隔。数字权重前缀（如 `1.3::`）按声明值着色，`{}` 使用增强色、`[]` 使用减弱色，闭合的 `::` 保留重置标记样式；文本按实际生效权重着色。悬浮文本或聚焦右上角图标可查看权重与语法诊断。切换模型保留原文与编辑历史，分析失败保留输入并提供重试。

输入自动触发本地词符计数，分词器与上限由 SDK 按实际模型选择，界面不展示词符 ID。输入框右侧的词符统计与词库入口采用无描边、方形边缘的图标按钮，统计浮层同时提供语法与权重信息。主提示词及每个角色标题显示有效提交用量的同心双环：外环为正面，内环为负面，各自超限时标红。主提示词统计包含追加的质量标签和负面预设，角色只统计本角色；折叠后仍可查看。悬浮、点击或键盘聚焦圆环，可查看两行进度条及已用 / 上限。未参与请求或尚未取得统计时，不显示为零用量。

### 注释

提示词支持 `//` 行注释与非嵌套的 `/* ... */` 块注释：

- 行注释仅在行首或空白之后开启，普通 URL 保留；使用 `\//` 或 `\/*` 写入字面符号。
- 普通引号不隔离注释，模型的文字渲染区域保留字面内容；随机分支导致注释含义不确定时会报告错误。
- 注释不能跨越文本片段；NAI 权重及其他模型语法仍可在组合后的作用域中连续生效。

原文随资源与当前创作保存，解析、计数和提交使用处理后的文本。未闭合或含义不确定的注释允许继续编辑与保存，修正前不能估费或提交。结果及图片元数据按原生提示词显示，恢复编辑时保护其中的字面注释符号。函数扩展尚未提供。

### 生成参数

模型、尺寸预设、自定义宽高和单请求样本数采用紧凑控件。模型名显示为“NAI Diffusion …”，采样器使用“Euler A”等简称，噪声调度和 Alpha 表示使用可读名称，图像与响应格式使用大写字母。质量标签与负面预设的选项和继承值同样显示可读名称，并随界面语言切换。下拉列表沿用应用主题，尺寸按“标准”“大尺寸”分组，显示“继承 (尺寸)”“横图 (尺寸)”等选项，末尾为“自定义”。“提示词选项”设置质量标签、负面预设、Furry 模式及模型支持的透明背景。

侧栏底部从上到下显示余额、四项参数摘要和生成按钮。水晶图标表示 Anlas 余额，闪电表示 Opus 额度，数值取自账户采样的 V5 额度百分比；未知值显示为横线，过期与失败保持可见。参数摘要展示步数、引导强度、种子和采样器，点击向上展开设置并隐藏余额；低频采样、输出和执行选项默认折叠。未配置账户时，余额区显示“需要配置账户”，底部按钮用于配置账户。

参数留空继承，显式关闭和零种子分别保留。模型选项、尺寸、样本范围及适用性来自 SDK，可选择自动调整或严格拒绝；字段错误会展开对应区域并定位。切换模型保留已有编辑值，不适用时显示诊断。

生成页配置活动账户后自动估费，修改参数、资源或账户采样后重新估算。主提示词和角色提示词的正负内容均可留空，空白提示词不阻止估费或提交；选中的质量标签与负面预设仍会生效。参数、资源或输入材料无效时，错误直接显示在生成按钮内，修正前不能提交；有可定位字段时提供定位入口，查询失败可重试。

## 图像操作

### 导入与元信息恢复

在“图像输入”选择文件、拖入单张 PNG / JPEG / WebP，或从“已有媒体”选图；结果工具栏也可直接“用作底图”。导入会保存实际图片，外部原文件移走不影响后续使用。仅查看源图或结果不会改写当前操作。

图片下方的单排图标提供信息、遮罩、换图与适用的高级设置，名称通过 tooltip 和可访问标签提供；移除入口位于区块标题右侧。参数紧凑排列在图片右侧，窄空间下改为上下排列，已应用遮罩显示在下方。

“图像信息与恢复”显示已知生成字段、元信息载体、角色文字和警告，并区分缺少信息、格式不支持及内容无效。用作底图保留当前提示词；恢复生成内容会先展示替换范围和缺失材料，再替换当前创作。恢复只使用已知信息，不补造遮罩、参考或角色位置，也不重复追加图片已包含的质量与负面标签。

同类操作换图保留已编辑参数；替换源图、离开图像操作或改变 Max Enhance 输入尺寸时，先确认影响范围。异步导入或准备若已被后续切换、恢复取代，不会覆盖新选择。

### 图生图、Max Enhance 与放大

| 操作        | 输入与设置                                                                            |
| ----------- | ------------------------------------------------------------------------------------- |
| 普通图生图  | 源图、Strength 与 Noise；高级浮层提供颜色校正、额外噪声种子和保留原图。               |
| Max Enhance | 沿用图生图设置，输入画布使用源图尺寸，显示 SDK 计算的输入、预计输出及计价尺寸。       |
| 独立放大    | 只使用源图、放大模型与 Blur Sigma，隐藏保留中的生成内容和无关参数；未知费用明确显示。 |

切换模型后，若 SDK 不再保留 Max Enhance，需改用支持的模型或明确选择普通图生图后提交。

### 局部重绘

从源图或结果工具栏选择“局部重绘”，在主画布绘制或擦除遮罩，可调整笔刷、撤回、重做与清除。支持原图、叠加及黑白遮罩预览；滚轮缩放，平移工具或鼠标中键移动，聚焦画布后也可使用方向键与加减键。白色区域重绘，黑色区域保留。

“应用遮罩”保存原生尺寸的独立黑白 PNG，并切换到局部重绘。可选择纯补绘或模型支持的局部图生图；后者提供 Strength 与 Noise，高级区提供颜色校正、额外噪声种子及保留遮罩外原图。尺寸适配、实际模型、诊断和费用由 SDK 决定；自动调整可切换到适用模型并关闭不适用的透明输出，严格模式拒绝隐式调整。

未应用笔画、撤回历史、笔刷与缩放平移按源图保存。离开画布、换图、换操作、切页或关闭时，可应用、保留或放弃未应用编辑。保留后可从“继续遮罩”恢复，关闭时保留则重启回到画布；放弃不删除已应用遮罩和原图。

任务只使用已应用材料，之后绘制不改变排队任务。结果详情可查看并恢复提交时的源图、遮罩与局部条件；恢复生成内容会保留尚未处理的画布编辑，干净画布重新打开时采用恢复的遮罩。

### 导演工具

独立页面提供描线、草图、去背景、情绪、清理、保留对白清理和着色。每项工具保留源图、专有参数、校验策略与选中输出；替换源图需确认，保留该工具已编辑的参数。提示词按工具需要显示，低频参数默认折叠。切页或重启可继续编辑，不改变创作页内容。

工具独立估费与提交，沿用[任务队列](#任务与结果)。结果区可比较输入与输出，选择全部产出、继续处理、发送回创作、用作适用参考、编码氛围转移或下载原文件。恢复工具结果只恢复对应工具的源图和参数。

### PNG 文本

在“图片元信息”的高级菜单打开“PNG 文本”，检查全部文本条目，添加写入项或选择已有关键字编辑。同名关键字按 ASCII 大小写不敏感匹配，写入时替换全部同名条目；新关键字追加，其余条目保留。空文本不会删除条目。

写入产生关联原图的新 PNG，保留像素与原资产，可再次检查、导出或用作底图。写入草稿及最近产出按图片保留，关闭面板或重启后可继续。

## 角色与参考材料

### 角色提示与定位

角色可分别编排正负提示词中的文本与片段，并管理启停、顺序和位置；也可保存到预设。实例可覆盖角色文字、启停与位置，撤销覆盖后继续使用原件，展开预设后保留有效角色内容。

“角色位置”提供继承、自动和使用坐标三种集合级选择；两名及以上角色时，集合设置与画布定位入口显示在角色上方。自动定位保留已编辑坐标，继承采用预设或 SDK 的选择。“在画布定位”进入主区，通过列表或标记选择角色，再点击、拖动或用方向键调整位置。网格、自由定位、默认位置与角色上限来自模型能力，切换模型保留编辑值，提交时使用 SDK 确定的实际位置。

### 精确参考

精确参考可导入图片或选择已有媒体，设置用途、Strength、Fidelity、信息提取量及逐项启停。原件、当前创作与实例覆盖使用相同字段；参考卡片沿用图像输入的图片与参数布局。Strength 和 Fidelity 保留 SDK 接受的有符号数值，不限制为 0–1。

启用且适用于当前模型与操作的精确参考会隐藏并停用本次请求的氛围转移，保留原编辑值，解除后恢复。支持角色提示不表示支持精确参考；不支持且没有已有条目时隐藏分组，已有条目保留并解释不适用原因。

解析与结果详情可查看角色文字、位置、词符用量、参考参数、材料及来源，并定位相关问题。提交冻结有效内容，恢复无需原片段或预设仍然存在。

### 氛围转移与编码

在“氛围转移”组打开“材料”，选择已有原图或编码。V3 使用原图，V4/V4.5 使用编码，材料类型不匹配时提示；是否支持以当前 SDK 能力为准。不支持或与精确参考冲突时隐藏分组，保留编辑值，切回适用状态后恢复显示。

每项参考可启停、排序并调整有符号强度；原图可调整信息提取量，编码强度归一化支持继承、开启与关闭。这些内容可保存到预设、建立实例覆盖或展开使用。

原图参考行提供编码按钮、预计费用及排队或执行状态。编码按源图、模型与提取参数查找已有材料或未完成任务；匹配时复用，否则由显式点击建立付费任务。完成后只更新仍保持原输入的那一行，更换或删除该行不会被迟到结果覆盖，编码材料仍保留。

编码在参考行和材料选择中查看、复用或导出，不进入图片预览、最近图片或画廊。带原图的材料可重新调整编码输入；只有编码时可复用，不能还原原图。

### 氛围转移文件交换

“材料”支持以下文件操作：

- 导入官方 `.naiv4vibe` 单文件与 `.naiv4vibebundle` 集合，查看各条目的原图及模型、参数缓存，明确选定后追加或替换当前参考；完整文档与未选缓存继续保留。
- 由原图创建文档、将文档组包、导出单文件或集合。
- 向 PNG 嵌入完整文档、读取 PNG 文档，或提取图片中的嵌入编码。

导出选定缓存的官方文件保留源条目的全部缓存身份。缺少模型身份的原始编码可导出原始文件，不能据此补造官方文件的模型身份。

## 任务与结果

### 估费与提交

本地校验无需凭据；生成页配置[账户](#账户与连接)后在生成按钮内自动显示预计 Anlas 消耗，显式点击才提交付费操作。“请求次数”为应用批次中的 1–8 次请求，每个请求对应独立任务；“样本数”为单请求产出，范围由 SDK 随模型和计价尺寸决定。随机种子在各请求准备时分别确定，显式种子按设置保留。

提交后内容、有效参数、媒体、凭据和执行设置固定，继续编辑不改变任务。未取得账户采样时按非订阅条件估算；已有采样也不表示实时余额或实际扣费承诺。任务详情分别保留 SDK 估算、请求终态和已有账户采样摘要，未知费用不显示为零，服务请求成功与结果保存成功分别表达。

### 队列、取消与重试

生成页和导演工具分别维护提交状态：点击后禁用本入口的提交按钮，显示提交、排队或工作中，直到本入口批次的全部请求进入终态；切页保留状态，另一入口仍可提交。提示词及参数仍可编辑，已提交任务使用冻结输入。

付费图像操作共用顺序队列，抽屉按批次显示排队、执行、完成、失败、取消和中断状态。可查看请求，取消单个请求或批次中的未完成请求。运行中的请求可能已被服务端处理，取消不保证免扣费。

复制种子与词库提示词的结果使用浮层通知，不挤占原有布局。批次结束时，窗口聚焦则显示应用内通知，未聚焦则使用系统通知；全部取消的批次不通知。任务详情保留可查看的状态和错误。Windows 系统通知的应用名称与图标需在安装后的应用中验证。

失败、取消或中断后，只有显式重试才使用原冻结内容、凭据和执行设置创建新任务，原记录保留。重启会将未完成任务标为中断，不自动续发。

### 预览、画廊与复用

高级生成设置可选择普通返回、SSE 或 MessagePack 预览。主区按所选请求显示等待、各样本实时预览及保存后的图片；多样本等分排列，可打开单张大图。预览保留到对应最终图片载入，查看历史或切页不会混用其他任务的帧。只显示实际步骤；收到最终样本仍需等待完整终态与结果保存，中间帧不进入历史。

最近图片默认显示 20 张，可在设置中调整为 1–200；完整历史通过画廊分页浏览。图片覆层可下载原图、查看有效参数与来源、用作后续图像操作或参考，以及恢复生成内容。实际样本种子可复制或填入参数。

恢复前确认替换范围，以独立文本和有效设置恢复当前创作，无需原资源仍然存在。样本种子未知时不补造；恢复原提交种子不承诺精确重现某个未知种子的样本。缺失或截断的媒体标为不可用，不能作为完整结果打开或恢复。

## 词库与画师

### 搜索与组合

词库是[按需安装](#资源下载)的本地资源，未安装时仍可编辑和生成。未安装时，结果区域显示空状态，可通过“前往资源下载”进入设置的资源下载分类。基础组件支持原名、可信别名与译名查询，无需模型；语义组件提供本地描述搜索。

顶部“词库”进入独立页面。搜索框旁切换常规与语义搜索，语义模式在准确命中后补充语义结果。左侧按普通词、画师、版权 / 作品、角色和元标签筛选；名称行可展开描述、来源、别名及“关联作品 / 题材”。风格只作为分组，画师无需中文译名，关联数据只表达作品或题材共现。

点击加号加入右侧有序组合，可移除、上移、下移和设置模型适用的数字权重或括号强调。预览后可复制，或作为新文本片段追加到当前创作的正面或负面提示词并返回创作。数字权重与括号强调分别保留，切换模型不互相解释。插入使用资源提供的提示词文本，自动保护结构字符及 nib 注释标记。

切页保留搜索、模式、分类与组合，重启恢复所在页面；临时组合不跨重启保存，命名复用仍通过片段 / 预设。资源更新或卸载会清除旧词条选择并提示重新选择。浏览和插入不触发付费预览。

### 编辑器联想与快捷弹窗

提示词编辑器在可替换标签范围显示联想：输入短暂停顿后查询，名称等词法结果先显示，可选语义结果随后补充。同一标签内持续输入时保留原候选列表，等待最新结果返回后替换，过期候选不可插入。选中词汇后自动追加 `, `，已有逗号时复用，光标移到分隔符后，可继续输入下一个标签。注释、文字渲染区域与不确定语义不参与标签替换。中文输入合成期间不插入；旧文本、光标、模型或资源版本的结果不会修改当前编辑，一次插入可用一次撤销恢复。

编辑器书本图标打开共用检索与组合界面的快捷弹窗。插入默认保留原文，显式选择文字时替换所选内容；只读编辑器只允许查询和复制。未安装词库时使用相同空状态，进入资源下载设置后关闭快捷弹窗。

## 设置与存储

设置按账户与连接、生成与预览、外观、存储、资源下载导航。主题、界面语言、执行配置与最近图片数量全局保存，启动时同步，修改后自动写入；失败时保留当前选择并提供重试。

### 账户与连接

可添加多个命名账户，编辑名称、更换 NovelAI API Key，并选择一个供后续操作使用。名称与选择保存在配置数据库，密钥只存于 Windows 凭据管理器，不进入前端持久存储、SQLite、日志或结果记录。更换 Key 建立新版本，已有任务及其重试继续使用提交时的版本；原凭据缺失时报错。有未完成任务引用时，删除账户会被阻止并提供查看任务入口。

配置活动账户后，后台自动采样订阅、Anlas 余额与 V5 额度；启动、账户或端点切换、任务结束和采样过期会触发合并查询。界面显示采样时间，失败保留同身份上次成功值并标记过期及错误，只在错误时提供重试。旧身份的迟到结果不覆盖新账户，账户变化会重新估费。

高级执行设置提供 API 端点基址、JSON / Multipart 请求编码及服务端图像缓存。默认使用 SDK 端点与 JSON，不启用缓存；基址供图像操作与账户查询共用，无需追加 API 路径，留空恢复默认。更改自动保存，新查询和提交使用新设置，已有任务及重试保留原设置；端点变化会重新采样账户。

### 外观与语言

提供黑白双主题，界面使用青绿主题色。语言支持跟随系统、English 和简体中文，默认跟随系统，未支持的语言使用英语。切换立即生效，保留编辑、弹窗和任务，日期、数字、帮助及错误说明随语言显示。提示词、用户命名、PNG 文本和路径不改写，SDK 与系统诊断详情保留原文。语言资源随应用打包，可离线切换。

### 数据位置与备份

正式环境默认位于桌面应用数据目录，分为：

| 目录         | 内容与用途                                                                   |
| ------------ | ---------------------------------------------------------------------------- |
| `config/`    | 固定位置；`settings.sqlite3` 保存偏好、账户元数据与数据目录选择。            |
| `data/`      | 创作数据库 `nib.sqlite3` 与 `media/`，保存资源、当前创作、任务、结果和媒体。 |
| `resources/` | 可重新下载的词库、索引与可选模型，不随创作数据迁移。                         |

设置中路径只读，可“打开位置”；“更改位置”通过原生目录选择器选择空目录，随后自动验证并迁移，无需输入路径或再次确认。该目录只表示存储位置，不提供工作区列表、新建或切换。

资源封面持久文件保存在 `media/resource-covers/`，与普通媒体分开；`media/thumbnails/` 是可重建的缩略图缓存。跨用途复用封面时创建普通图片副本，不借用资源独占的封面文件。

迁移前先保存当前创作与全局设置，未保存资源需先返回资源库处理。迁移期间暂停编辑和新请求，等待已发请求及结果保存，再复制、同步并验证数据库与媒体，成功后才更新位置。当前窗口保持只读，重启使用新目录；失败恢复原目录写入和调度。中断复制可在同一目标重试，旧目录始终保留。

备份创作时保存整个数据目录，全局设置另行备份配置目录。开发模式默认使用仓库 `.dev/` 下相同的三个子目录，设置、凭据与资源均与正式环境隔离；隔离开发实例见[开发说明](development.md#持久化与边界表示)。

### 资源下载

“设置 → 资源下载”提供基础词库与可选语义组件的安装和管理，显示已安装及可用版本、组件选择、大小、进度与错误，资源用途通过标题旁的帮助入口查看。主操作用于安装、更新或应用组件更改，管理菜单提供重新安装与卸载，下载中可取消，失败后可重试。资源目录显示在列表下方，可刷新下载目录信息。

语义组件依赖基础组件，选择时自动包含依赖；重新打开管理界面会恢复已有安装或未完成任务的组件选择。减少组件或卸载前列出受影响能力并确认。新资源完整校验后才启用，失败或取消保留当前可用版本。任务由后台持有，切页不会停止下载。
