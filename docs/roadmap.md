# nib 路线图

本文只记录未完成工作、实施依赖与验收条件，不作为发布承诺。当前能力与用法见[功能说明](features.md)，产品概念见[设计说明](design.md)，工程约束见[开发说明](development.md)。

先收口真实服务验收，再按资源积累推进组织与可携带性。每项能力需覆盖界面、状态保留、实际提交和结果复用，不以新增表单或 API 封装作为完成标准。

## 本地图像分析验收

- 验收模型在公开下载目录中的安装、取消、卸载及重新安装。
- 使用真实模型验收生成最终图的自动评分、临界分数 WD 复核、历史未知结果补查，以及普通和角色标签提取与回填。
- 人工检查各图片入口的 NSFW 模糊、首次点击临时显示、换图复位和详情豁免；重绘与定位的首次显示操作不得同时修改画布。

## 探索验收

- 使用真实 Danbooru 账户验收验证、更换 Key、认证失效与断开，确认生成账户和冻结任务不受影响。
- 人工验收两个来源的搜索、分页、详情、限流反馈、图片保存与材料复用，以及缺失元信息时的恢复预览。
- 检查深浅主题、1280×720 布局、键盘操作、模糊临时显示与切换来源后的浏览上下文保留。

## Agent 验收

- 使用真实云端 API 与自定义兼容端点，分别验收 Chat Completions 和 Responses 的流式对话、工具调用、认证失败与取消。
- 人工验收接管前保存、运行中编辑锁定、取消或失败后同步、旧保存拒绝、当前创作与资源撤销，以及重新启动后的中断反馈。
- 验收提示词实例覆盖、参数继承、词库未安装、资源查询与整理、未保存原件阻止接管，并检查两个主题、键盘操作与最小窗口布局。
