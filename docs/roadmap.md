# nib 路线图

本文只记录未完成工作、实施依赖与验收条件，不作为发布承诺。当前能力与用法见[功能说明](features.md)，产品概念见[设计说明](design.md)，工程约束见[开发说明](development.md)。

先收口真实服务验收，再按资源积累推进组织与可携带性。每项能力需覆盖界面、状态保留、实际提交和结果复用，不以新增表单或 API 封装作为完成标准。

## 启动与资源恢复验收

- 使用已安装词库和图像模型的正式构建，人工确认进入工作台不等待资源恢复，并观察启动与各资源恢复的分阶段耗时。
- 验收恢复中的加载提示、损坏资源错误与重新安装，以及恢复期间更新或卸载后不会重新启用旧资源。
- 使用真实资源验收首次语义搜索、编辑器普通补全与语义补全、首次安全评分及标签提取；确认关闭自动评分且未主动分析时不初始化图像模型。
- 验收语义总开关的保存与重启恢复、加载或检索期间关闭、快速关闭再开启、关闭期间安装资源；确认普通检索与选择保留，旧语义结果不再显示，关闭后语义资源随已有操作结束释放。

## 本地图像分析验收

- 验收模型在公开下载目录中的安装、取消、卸载及重新安装。
- 使用真实模型验收生成最终图的自动评分、临界分数 WD 复核、历史未知结果补查，以及普通和角色标签提取与回填。
- 人工检查各图片入口的 NSFW 模糊、首次点击临时显示、换图复位和详情豁免；重绘与定位的首次显示操作不得同时修改画布。

## 探索验收

- 使用真实 Danbooru 账户验收验证、更换 Key、认证失效与断开，确认生成账户和冻结任务不受影响。
- 人工验收两个来源的搜索、分页、详情、限流反馈、图片保存与材料复用，以及缺失元信息时的恢复预览。
- 检查深浅主题、1280×720 布局、键盘操作、模糊临时显示与切换来源后的浏览上下文保留。

## Agent 验收

- 使用真实供应商验证预设、模型列表自动拉取、刷新、失败后手填与切换端点；确认已保存 Key 不会用于不同地址。
- 人工验收文件和剪贴板图片、纯图片消息、重启后附件及工具图片、工作台结果读取，并确认视觉模型收到实际图像。
- 人工验收流式 Markdown、CJK 标点附近的强调与链接、未完成代码块，以及 Agent 运行期间的对话及历史缩略图读取与失败重试。
- 使用真实 NovelAI 账户验收逐次批准、拒绝、自动允许与禁止，核对费用预览、冻结请求、生成结果回读及等待批准或生图期间取消后的任务状态。
- 使用真实云端 API 与自定义兼容端点，分别验收 Chat Completions 和 Responses 的流式对话、工具调用、认证失败与取消。
- 人工验收接管前保存、运行中编辑锁定、取消或失败后同步、旧保存拒绝、当前创作与资源撤销，以及重新启动后的中断反馈。
- 验收提示词实例覆盖、参数继承、词库未安装、资源查询与整理、未保存原件阻止接管，并检查两个主题、键盘操作与最小窗口布局。

## Windows 分发验收

- 验证旧版本补发与后续资源发布不会替换应用 Latest。
- 在普通 Windows 用户环境验收首次安装、连续两个正式版本的应用内更新与重启，确认运行库依赖完整、数据及凭据保留。
- 人工验收资源与遮罩保存保护、助手及生成队列忙时暂缓安装、失败后恢复编辑，以及签名无效、下载失败和 schema 升级失败的处理。
