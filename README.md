# nib

nib 是本地优先、专用于 NovelAI 的桌面创作工作台。原生图像操作与可组合的 Prompt 资源系统共同构成产品核心：用 Chunk 积累提示词片段，用 Preset 组合创作配方，工作台自动保留当前创作。

生成内核直接复用 [novelai-bridge](https://github.com/RhNu/novelai-bridge)，应用采用 Rust 模块化单体、Tauri 和 React / TypeScript。

## 当前能力

已实现资源与当前创作的本地工作台：创建和查找纯文本 Chunk，以 Preset 组合提示词、角色、Vibe、精确参考及显式默认设置，在当前创作中使用资源引用、实例覆盖和独立展开内容。文生图、图生图、Max Enhance、局部重绘、独立放大、角色定位、七项导演工具、PNG 文本检查与写入、Vibe 参考与编码、官方 Vibe 文件交换、精确参考、图片元信息恢复、提示辅助、账户快照及结果复用均有界面入口。解析面板显示实际文本、来源、设置覆盖与缺失依赖；资源和当前创作通过真实 IPC 保存到 SQLite。无需凭据即可本地估费，配置 NovelAI API Key 后可提交任务并查看最终结果。

界面采用扁平紧凑的黑白双主题和青绿主题色，顶部集中创作、导演工具、资源库与设置。左侧生成栏组合提示词、图像输入、参考与角色，生成参数位于底部可折叠区域，右侧查看源图、流式预览、大图与结果缩略条，并在同一主区编辑遮罩或角色位置；资源选择和解析按需打开。启动应用不需要 NovelAI 凭据，只有显式提交或重试才会发起付费操作。[设计说明](docs/design.md)中的完整产品目标不代表当前功能均已可用，真实服务验收的剩余范围见[路线图](docs/roadmap.md)。

## 启动

当前开发与构建目标为 Windows x64。准备以下环境：

- Visual Studio 的 C++ 桌面开发工具及 Windows SDK。
- Microsoft Edge WebView2 Runtime。
- Rustup；仓库固定 Rust 1.99.0，包含 rustfmt 和 Clippy。
- Node.js 24.21.0、pnpm 12.14.0，分别由 `.node-version` 和 `packageManager` 声明。

平台依赖安装见 [Tauri 官方前置条件](https://v2.tauri.app/start/prerequisites/)。在仓库根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

预期出现带自定义标题栏的 nib 工作台，首次打开时进入空白工作台。开发服务固定使用 `127.0.0.1:1420`；端口占用时会报错，不会静默切换端口。

仅查看浏览器前端可运行 `pnpm dev:web`。浏览器模式会明确提示缺少桌面宿主，不能用于确认 IPC 已连通。

## 本地创作

资源库在独立页面中提供搜索、筛选、列表与原件编辑；切换页面保留搜索、选中项和未保存修改，关闭窗口前仍须保存或放弃资源修改。

在“资源库”中新建 Chunk，填写名称和文本并保存；新建 Preset 时，可以为两个提示词作用域分别组合文本和 Chunk，只填写配方负责的默认设置。资源名称允许重复，引用使用稳定身份。

在当前创作中添加文本、Chunk 或 Preset，可以启用、停用和调整顺序。编辑引用内容或配方设置只建立当前实例的覆盖；撤销覆盖后继续使用原资源。展开 Chunk 会得到独立文本；展开 Preset 会保留当前内容、启用状态及合并后的设置，解除资源引用。解析按配方顺序组合内容，再追加当前创作的直接片段，片段间以换行分隔，保留原有提示词语法。

生成栏主体按模型、提示词与质量/负面预设、配方、图像输入、Vibe、精确参考与角色、尺寸与样本数排列。底部提交区上方的“生成参数”默认展开，可独立滚动或折叠，依次提供 Steps、Guidance、种子与采样器；其中“高级设置”默认折叠，输出与执行选项在同一层展开，隐藏字段出错时自动展开并定位。参数留空继承，显式关闭和零种子分别保留；模型选项与范围来自 SDK。高级区可选择自动调整或严格拒绝，SDK 诊断与错误可定位到字段，切换模型不会清除已有设置。

文本片段、Chunk 和实例覆盖旁可打开本地 Token 检视，查看字面文本的计数与 Token IDs；生成栏另显示追加质量和负面预设后的有效提示词用量。英日标签建议由显式查询触发，需要凭据和网络，选择后插入原光标或选区。

修改提示词、资源实例、生成参数或 Vibe 编码输入后，工作台会自动保存当前创作；关闭窗口前等待写入，失败时保留编辑并提示重试。重新打开工作台会恢复这份状态。命名复用通过 Chunk 和 Preset 完成，资源定义编辑需要单独保存，未保存时离开会要求处理修改。删除资源会保留已有引用并显示缺失问题。

## 设置与存储

主题等应用偏好由后端全局保存，启动时同步，修改后自动写入；写入失败时保留当前选择并提供重试。所有应用设置均独立于创作数据的位置，API Key 仍由系统凭据管理器保存。

设置页的“高级执行设置”默认折叠，可选择 JSON 或 Multipart 图像请求编码及服务端图像缓存；默认沿用 SDK 的 JSON、不启用缓存。更改只作用于新提交的任务，已排队任务及其重试保留原执行设置。更改执行设置会重建客户端并清除旧账户快照，需要时可显式刷新。

正式环境默认使用桌面应用数据目录下的 `config/` 和 `data/`。`config/settings.sqlite3` 保存全局偏好与数据目录位置，配置目录固定；`data/` 保存 `nib.sqlite3` 与 `media/`。设置页显示实际路径，可指定空目录作为新的数据目录，或恢复默认位置。目录只是存储位置，没有工作区列表、新建或切换功能。

更改数据目录在下次启动时生效，数据库与媒体一起复制；全部写入后才启用新目录，失败时不会切换或自动创建空库替代原数据，可以重试或在设置中取消待生效的更改。迁移会暂时占用两份存储空间，旧目录保留，确认新目录数据可用后可自行清理。恢复默认位置同样要求目标为空。备份创作时保存整个数据目录；全局设置需另外备份配置目录。

`pnpm dev` 使用项目根目录下的 `.dev/config/` 和 `.dev/data/`，已排除在 Git 之外；开发与正式环境的设置和凭据相互独立。

## 生成与结果复用

### 从图片开始

在配方之后的“图像输入”中选择文件、拖入单张 PNG / JPEG / WebP，或从“已有媒体”选图；结果工具栏也能直接“用作底图”。图片内容导入应用后通过稳定身份引用，外部原文件移走不会影响后续编辑。可在主区切换查看源图与结果。

普通图生图提供 Strength、Noise，高级区提供颜色校正、额外噪声种子和保留原图。Max Enhance 保留这些设置，将输入画布设为源图尺寸，并显示 SDK 计算的输入、预计输出及计价尺寸。若切换模型后 SDK 不再保留 Max Enhance，必须改用支持的模型或明确选择普通图生图后提交。独立放大只使用源图、模型与 Blur Sigma，隐藏保留中的生成内容和无关参数；未知费用显示“费用未知”。

同类操作换图保留已编辑参数；替换源图、离开图像操作或改变 Max 输入尺寸时，先确认将更改的范围。选择页、折叠或导航不会改写当前操作。新的导入或操作准备在完成前被切换或恢复取代时，不会覆盖后续选择。

“图像信息与恢复”可检查已知生成字段、元信息载体、角色文字和警告；缺少信息、格式不支持、内容无效分别显示。仅用作底图保留当前提示词；恢复生成内容会先展示将替换的内容及缺失材料，再明确替换当前创作。恢复不补造遮罩、参考或角色位置，不重复追加图片已包含的质量与负面标签。

### 局部重绘

从源图或结果工具栏选择“局部重绘”，在同一主画布绘制或擦除遮罩，调整笔刷、撤回、重做和清除。可切换原图、叠加与黑白遮罩预览；滚轮缩放，平移工具或鼠标中键移动，聚焦画布后也可使用方向键与加减键。白色区域重绘，黑色区域保留。

“应用遮罩”把原生尺寸的黑白 PNG 保存为独立媒体，并将当前操作切换为局部重绘。左栏可选择纯补绘或模型支持的局部图生图，后者提供 Strength、Noise；颜色校正、额外噪声种子与保留遮罩外原图位于默认折叠的高级区。适用能力、尺寸适配、诊断和费用均来自 SDK。

V5 Curated 局部重绘按官网使用 V4.5 Curated，能力选项、Token、估费和结果记录随实际模型调整；自动调整模式关闭不适用的透明输出并显示诊断，严格模式拒绝隐式切换模型。

未应用笔画、撤回/重做记录、笔刷与缩放平移按源图独立保存；离开画布、换图、换操作、切页或关闭时，可应用、保留或放弃未应用编辑。保留后从“继续遮罩”恢复，关闭时保留则重启直接回到画布。放弃只撤去未应用编辑，已应用遮罩和原图仍保留。编辑中的未应用遮罩不会用于提交；任务始终冻结已应用材料，之后继续绘制不改变排队任务。结果详情可查看并恢复提交时的源图、遮罩与局部条件。

### 角色与精确参考

在侧栏添加角色，为每个角色分别编排正负提示词、文本与 Chunk，并管理启停、顺序和位置。角色也可保存到 Preset；当前实例可覆盖角色文字、启停或位置，撤销覆盖后继续使用原件。展开 Preset 会保留角色与参考内容，解除资源引用。

“角色位置”提供继承、自动和使用坐标三种集合级选择；自动定位保留已编辑坐标，继承继续采用配方或 SDK 的选择。“在画布定位”进入主区，通过角色列表或标记选择角色，再点击、拖动或使用方向键调整位置。网格与自由定位、默认位置及角色上限来自模型能力；切换模型保留编辑值，提交时由 SDK 计算实际生效位置。

精确参考可导入或选择已有图片，设置用途、强度、Fidelity、信息提取量及逐项启停。原件、当前创作和实例覆盖共享这些字段，图片通过已保存媒体引用。模型与操作支持、参考冲突分别显示；支持角色提示不代表支持精确参考。强度和 Fidelity 保留 SDK 接受的有符号数值，不限制为 0–1。

解析和结果详情可查看角色文本、位置、本地 Token 用量，以及精确参考参数、材料和来源。问题可定位到对应角色或配方实例；提交冻结有效内容，恢复结果无需原 Chunk 或 Preset 仍存在。

### Vibe 参考、编码与文件

在“Vibe”组打开“材料”，选择已有原图或编码，或导入官方 `.naiv4vibe` 单文件与 `.naiv4vibebundle` 集合。文档详情列出每个条目的原图及模型、参数缓存，选定后才能追加或替换当前参考；完整文档和未选缓存继续保留。V3 使用原图参考，V4/V4.5 使用编码参考，模型路径与精确参考冲突会明确显示。每项参考可启停、排序并调整有符号强度，原图还可调整信息提取量；编码强度归一化支持继承、开启和关闭。这些内容同样可保存到 Preset、建立实例覆盖或展开使用。

点击“编码”打开独立表单，选择源图、编码模型与信息提取量；高级项提供可选遮罩、裁剪、Focus Seed 和信息提取种子。编码有单独的费用与提交按钮，编辑或关闭表单会保留输入，不改变当前生成操作。改变模型、提取量、遮罩或种子后需要显式再次编码，添加已有编码不会触发编码请求。

编码结果在结果区显示为材料卡片，可查看模型、参数身份及来源，添加到参考或导出原始编码与官方单文件；有可用源图及所需遮罩时可带回编码表单重新调整。没有原图的编码可继续复用；需要重新编码时先从文档选择原图或另行提供图片。

“材料”中的文件操作可由原图创建文档、将文档组包、导出单文件或集合、向 PNG 嵌入完整文档、读取 PNG 文档，以及提取图片中的嵌入编码。导出选定缓存的官方文件会保留源条目的全部缓存身份；缺少模型身份的原始编码可导出原始文件，不能据此补造官方文件的模型身份。

### 导演工具与 PNG 文本

“导演工具”页提供描线、草图、去背景、情绪、清理、保留对白清理和着色。每个工具独立保留源图、专有参数、校验策略与选中输出；从图片结果发送或选择另一张源图时，确认替换后仍保留该工具已编辑的参数。Prompt 按工具需要显示，低频参数默认折叠。切换页面或重启可继续编辑，不改变创作页内容。

工具使用独立估费与提交，沿用顺序队列、取消、显式重试和重启中断规则。结果区可比较输入与输出，选择全部产出、继续处理、发送回创作、用作适用参考、编码 Vibe 或下载原文件；恢复工具结果只恢复对应工具的源图和参数。

在“图片元信息”的高级菜单打开“PNG 文本”，检查图片的全部文本条目，添加写入项或选择已有关键字编辑。同名关键字按 ASCII 大小写不敏感匹配并替换全部同名条目，新关键字追加，其余条目保持原样；空文本不会删除条目。写入后生成关联原图的新 PNG，保留像素和原资产，可再次检查、导出或用作底图。写入草稿及最近产出按图片保留，关闭面板或重启后重新打开可继续。

### 提交与再次使用

通过“设置 → 账户”输入 NovelAI API Key，宿主将其保存在 Windows 凭据管理器中；可以在同一入口替换或移除。凭据不会写入前端本地存储、SQLite、日志或结果记录。保存凭据不验证远程账户，也不产生生成费用。

账户页可显式刷新订阅、Anlas 余额和 V5 额度，并显示采样时间；启动只读取本地状态，不自动查询远程账户。刷新或更换凭据后重新估费，刷新期间不能沿用旧估算提交。

当前创作通过 SDK 本地校验和估费后，点击“生成”将确定的内容加入顺序队列。未显式取得账户快照时按非订阅条件估算；已有快照仍不代表实时余额或实际扣费承诺。提交后的文本、参数、随机种子及必要来源固定，继续修改资源或当前创作不会改变已提交任务。

生成参数的高级区可选择普通返回、SSE 或 MessagePack 预览，选择随当前创作保留。任务区可查看指定任务及样本的实时预览和实际步骤，查看历史图片或切换页面不会串用其他任务的帧。“已接收最终样本”仍须等待完整终态与结果保存；断流或缺少最终样本不会产生成功结果，中间帧也不进入历史。

任务区显示排队、执行、完成、失败、取消和中断状态。可以取消任务；运行中的请求可能已被服务端处理，取消不保证免扣费。失败、取消或中断后，只有显式重试才重新提交原来的内容。重新打开应用不会自动续发未完成的请求。

任务详情保留 SDK 请求估算、请求终态和执行时已有的账户采样摘要。服务请求返回成功与结果保存成功分别表达；这些观察不等于实际扣费，未知费用不会显示为零。

最终图片存于数据目录的 `media/`，结果记录存于同目录的 SQLite。结果区展示各样本，可下载原始文件、查看全部有效参数与来源、仅使用已知样本种子，或恢复内容后再次生成。确认恢复后，以独立文本和有效设置替换当前创作，无需原资源仍然存在。样本种子未知时明确提示，缺失或截断的图片会标为不可用，不能当作完整结果打开或恢复。

## 开发入口

```sh
pnpm build:web
pnpm build:desktop
```

桌面构建生成 Windows 可执行程序，不生成安装包或更新包。完整检查使用 `pnpm check`，还需本机具备 Rusteward 的 `cargo-dev` 和 rumdl；安装、类型生成及命令职责见[开发说明](docs/development.md)。
