# nib

nib 是本地优先、专用于 NovelAI 的桌面创作工作台。原生图像操作与可组合的 Prompt 资源系统共同构成产品核心：用 Chunk 积累提示词片段，用 Preset 组合创作配方，工作台自动保留当前创作。

生成内核直接复用 [novelai-bridge](https://github.com/rhnu/novelai-bridge)，应用采用 Rust 模块化单体、Tauri 和 React / TypeScript。

## 当前能力

已实现资源与当前创作的本地工作台：创建和查找纯文本 Chunk，以 Preset 组合提示词、角色、氛围转移、精确参考及显式默认设置，在当前创作中使用资源引用、实例覆盖和独立展开内容。文生图、图生图、Max Enhance、局部重绘、独立放大、角色定位、七项导演工具、PNG 文本检查与写入、氛围转移参考与行内编码、官方氛围转移文件交换、精确参考、图片元信息恢复、自动 Token 计数、账户采样及结果复用均有界面入口。解析面板显示实际文本、来源、设置覆盖与缺失依赖；资源和当前创作通过 IPC 保存到 SQLite。无需凭据即可本地估费，配置 NovelAI API Key 后可提交任务并查看最终结果。

界面采用扁平紧凑的黑白双主题和青绿主题色，顶部集中创作、导演工具、画廊、资源库与设置。左侧生成栏组合提示词、图像输入、参考与角色，参数使用紧凑网格和按需浮层；右侧在同一位置显示等待、流式预览和最终图片，多样本使用等分网格。最近图片位于下方，完整图片历史进入画廊，任务队列从抽屉打开；遮罩或角色位置也在主区编辑。启动应用不需要 NovelAI 凭据，只有显式提交或重试才会发起付费操作。[设计说明](docs/design.md)中的完整产品目标不代表当前功能均已可用，真实服务验收的剩余范围见[路线图](docs/roadmap.md)。

## 启动

当前开发与构建目标为 Windows x64。准备以下环境：

- Visual Studio 的 C++ 桌面开发工具及 Windows SDK。
- Microsoft Edge WebView2 Runtime。
- Rustup；仓库固定 Rust 1.99.0，包含 rustfmt、Clippy 和 `wasm32-unknown-unknown` 目标。
- 与锁文件中 wasm-bindgen 同版本的 `wasm-bindgen-cli`，当前为 0.2.130。
- Node.js 24.21.0、pnpm 12.14.0，分别由 `.node-version` 和 `packageManager` 声明。
- Python 3.12–3.14 用于统一检查中的资源工具单元测试；构建词库资源时另需 uv 和工具的锁定依赖。

平台依赖安装见 [Tauri 官方前置条件](https://v2.tauri.app/start/prerequisites/)。在仓库根目录运行：

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.130 --locked
pnpm install --frozen-lockfile
pnpm dev
```

预期出现带自定义标题栏的 nib 工作台，首次打开时进入空白工作台。开发服务固定使用 `127.0.0.1:1420`；端口占用时会报错，不会静默切换端口。

仅查看浏览器前端可运行 `pnpm dev:web`。浏览器模式会明确提示缺少桌面宿主，不能用于确认 IPC 已连通。

## 本地创作

资源库在独立页面中提供搜索、筛选、列表与原件编辑；切换页面保留搜索、选中项和未保存修改，关闭窗口前仍须保存或放弃资源修改。

在“资源库”中新建 Chunk，填写名称和文本并保存；新建 Preset 时，可以为两个提示词作用域分别组合文本和 Chunk，只填写配方负责的默认设置。资源名称允许重复，引用使用稳定身份。

在当前创作中添加文本、Chunk 或 Preset，可以启用、停用和调整顺序。编辑引用内容或配方设置只建立当前实例的覆盖；撤销覆盖后继续使用原资源。展开 Chunk 会得到独立文本；展开 Preset 会保留当前内容、启用状态及合并后的设置，解除资源引用。解析按配方顺序组合内容，再追加当前创作的直接片段，片段间以换行分隔，保留原有提示词语法。

生成栏主体按模型、主提示词与角色、配方、图像输入、参考、尺寸和样本数排列。提示词旁的图标打开“提示词选项”，设置质量标签、负面预设、Furry 模式及模型支持的透明背景；尺寸预设和自定义宽高、单请求样本数使用紧凑控件，步数、Guidance、种子和采样器位于底部可折叠参数区。高级设置默认折叠，字段错误会展开并定位。参数留空继承，显式关闭和零种子分别保留；模型选项、尺寸预设和样本范围来自 SDK。可选择自动调整或严格拒绝，切换模型不会清除已有设置。

基础、负面、角色、Chunk、实例覆盖及解析文本共用 CodeMirror 提示词组件，采用内置 Maple Mono CN 等宽字体。高亮与权重分析按实际模型自动适配括号、数字权重、随机分支、混合提示词及角色分隔；悬浮文本或聚焦右上角图标可查看权重与语法诊断。切换模型保留原文和编辑历史；分析失败保留输入并提供重试。输入自动触发本地 Token 计数，分词器由 SDK 按实际模型选择。生成栏的主提示词及每个角色标题显示有效提交用量的同心双环：外环为正面，内环为负面，各自使用模型的独立上限，超限时对应环标红。主标题只统计主提示词，包含追加的质量标签和负面预设；角色标题只统计本角色，折叠后仍可查看。悬浮、点击或键盘聚焦圆环可查看两行进度条与已用 / 上限；未参与请求的角色和尚未取得统计的状态不显示为零用量。

提示词支持 `//` 行注释和非嵌套 `/* ... */` 块注释。行注释仅在行首或空白之后开启，普通 URL 保留；使用 `\//` 或 `\/*` 写入字面符号。普通引号不隔离注释，模型的文字渲染区域保留字面内容；随机分支导致注释含义不确定时会提示错误。注释原文随资源和当前创作保存，解析、计数和提交使用处理后的文本。注释不能跨越文本片段；NAI 权重及其他模型语法仍可在组合后的作用域中连续生效。未闭合或含义不确定的注释可继续编辑、保存，但须修正后才能估费或提交。结果及图片元数据按原生提示词显示，恢复编辑时保留其中的字面注释符号。函数扩展尚未提供。

修改提示词、资源实例、生成参数或氛围转移编码输入后，工作台会自动保存当前创作；关闭窗口前等待写入，失败时保留编辑并提示重试。重新打开工作台会恢复这份状态。命名复用通过 Chunk 和 Preset 完成，资源定义编辑需要单独保存，未保存时离开会要求处理修改。删除资源会保留已有引用并显示缺失问题。

## 词库与画师

词库是按需安装的本地资源。未安装时仍可正常编辑和生成；在“设置 → 资源下载”选择基础词库及可选语义搜索组件。统一资源管理界面显示各资源及组件的用途、已安装与可用版本、大小、进度和错误，支持刷新目录、安装、更新、重新安装、取消、重试和卸载。语义组件依赖基础词库，选择时自动包含依赖；重新打开管理界面保留已有安装或未完成任务的组件选择。移除组件和卸载前会列出受影响能力并确认，新资源完整校验后才切换，失败或取消保留当前可用版本。下载由桌面宿主持有，切换页面或关闭管理弹窗不会停止任务。

基础词库支持原名、可信别名与译名查询，无需模型；安装语义资源后可在停顿输入时按描述查询。共享 CodeMirror 提示词入口在可替换标签范围显示联想，名称等词法结果先显示，语义结果随后补充。注释、文字渲染区域与不确定语义不参与标签替换。中文输入合成期间不插入，旧文本、光标、模型或资源版本的返回结果不会修改当前编辑；一次插入可用一次撤销恢复。只读提示词可查询而不能插入。

各编辑器的书本图标打开“词库与画师”，资源库工具栏也提供独立浏览入口。“管理资源”打开与设置页共用的通用管理弹窗，保留搜索、分类与已选词条。普通词、画师、版权 / 作品、角色和元标签分开分类，风格仅作为词条分组；画师可用英文、假名和可信别名查找，不要求存在中文译名。可多选词条，并按当前模型配置数字权重或括号强调层数，插入当前编辑器；已有文本默认保留，显式选择文字时替换所选内容。词条中的结构字符与注释标记由共享 Rust formatter 保护，组合仍以普通提示词保存到既有 Chunk 或 Preset，不创建另一套画师配方。来源增强包有共现数据时可查看“关联作品 / 题材”，没有关联数据时明确显示为空；查询与插入不发起付费预览。

## 设置与存储

设置左侧按“账户与连接、生成与预览、外观、存储、资源下载”导航，右侧编辑对应内容。主题、界面语言、执行配置和最近图片数量由后端全局保存，启动时同步，修改后自动写入；写入失败时保留当前选择并提供重试。最近图片默认显示 20 张，可设置为 1–200 张，完整历史在画廊中浏览。应用设置独立于创作数据位置，API Key 由 Windows 凭据管理器保存。

“外观”提供跟随系统、English 和简体中文三种语言选择，默认跟随系统，未支持的语言使用英语。切换立即生效，保留当前编辑、弹窗和任务；日期、数字、帮助及错误说明随界面语言显示。提示词、资源名称、PNG 文本和路径保持原值，SDK 与系统返回的诊断详情保留原文。语言资源随应用打包，离线也能切换。

“账户与连接”的高级执行设置可配置 API 端点基址、JSON 或 Multipart 图像请求编码及服务端图像缓存；默认使用 SDK 端点与 JSON，不启用缓存。图像操作与账户查询共用此基址，无需追加具体 API 路径，留空恢复默认。更改自动保存，后续查询与新提交任务使用新设置，已有任务及其重试保留原执行设置。端点变化会自动重新采样账户。

正式环境默认使用桌面应用数据目录下的 `config/`、`data/` 和 `resources/`。`config/settings.sqlite3` 保存全局偏好、账户名称与选择、数据目录位置；配置目录固定。`data/` 保存 `nib.sqlite3` 与 `media/`。`resources/` 独立保存可重新下载的词库、索引和可选模型，不随创作数据迁移。设置页只读显示路径并提供“打开位置”；“更改位置”使用原生目录选择器，选择后自动验证并开始迁移，不需要输入路径或再次确认。目录只是存储位置，没有工作区列表、新建或切换功能。

迁移前先保存当前创作与全局设置；资源有未保存修改时，先返回资源库处理。迁移期间暂停编辑和新请求，等待已发出的付费请求及结果保存完成，再复制、同步并验证数据库与媒体，成功后才更新数据位置。当前窗口保持只读，重启后使用新目录；失败时保留原目录并恢复保存和调度。目标目录须为空；中断复制可在同一目标重试。旧目录保留，备份创作时保存整个数据目录，全局设置另行备份配置目录。

`pnpm dev` 默认使用项目根目录下的 `.dev/config/`、`.dev/data/` 和 `.dev/resources/`，已排除在 Git 之外；开发与正式环境的设置、凭据和下载资源相互独立。隔离开发实例的目录配置见[开发说明](docs/development.md#持久化与边界表示)。

## 生成与结果复用

### 从图片开始

在配方之后的“图像输入”中选择文件、拖入单张 PNG / JPEG / WebP，或从“已有媒体”选图；结果工具栏也能直接“用作底图”。图片内容导入应用后通过稳定身份引用，外部原文件移走不会影响后续编辑。可在主区切换查看源图与结果。

图像输入左侧显示源图预览，信息、遮罩、换图与高级设置按适用性集中在图片底部的单排图标覆层中，移除入口位于区块标题右侧；右侧紧凑排列操作选择与对应参数，窄空间下改为上下排列。已应用遮罩显示在下方。普通图生图提供 Strength、Noise 数值与滑块，高级浮层提供颜色校正、额外噪声种子和保留原图。Max Enhance 保留这些设置，将输入画布设为源图尺寸，并显示 SDK 计算的输入、预计输出及计价尺寸。若切换模型后 SDK 不再保留 Max Enhance，必须改用支持的模型或明确选择普通图生图后提交。独立放大只使用源图、模型与 Blur Sigma，隐藏保留中的生成内容和无关参数；未知费用显示“费用未知”。

同类操作换图保留已编辑参数；替换源图、离开图像操作或改变 Max 输入尺寸时，先确认将更改的范围。选择页、折叠或导航不会改写当前操作。新的导入或操作准备在完成前被切换或恢复取代时，不会覆盖后续选择。

“图像信息与恢复”可检查已知生成字段、元信息载体、角色文字和警告；缺少信息、格式不支持、内容无效分别显示。仅用作底图保留当前提示词；恢复生成内容会先展示将替换的内容及缺失材料，再明确替换当前创作。恢复不补造遮罩、参考或角色位置，不重复追加图片已包含的质量与负面标签。

### 局部重绘

从源图或结果工具栏选择“局部重绘”，在同一主画布绘制或擦除遮罩，调整笔刷、撤回、重做和清除。可切换原图、叠加与黑白遮罩预览；滚轮缩放，平移工具或鼠标中键移动，聚焦画布后也可使用方向键与加减键。白色区域重绘，黑色区域保留。

“应用遮罩”把原生尺寸的黑白 PNG 保存为独立媒体，并将当前操作切换为局部重绘。左栏可选择纯补绘或模型支持的局部图生图，后者提供 Strength、Noise；颜色校正、额外噪声种子与保留遮罩外原图位于默认折叠的高级区。适用能力、尺寸适配、诊断和费用均来自 SDK。

V5 Curated 局部重绘按官网使用 V4.5 Curated，能力选项、Token、估费和结果记录随实际模型调整；自动调整模式关闭不适用的透明输出并显示诊断，严格模式拒绝隐式切换模型。

未应用笔画、撤回/重做记录、笔刷与缩放平移按源图独立保存；离开画布、换图、换操作、切页或关闭时，可应用、保留或放弃未应用编辑。保留后从“继续遮罩”恢复，关闭时保留则重启直接回到画布。放弃只撤去未应用编辑，已应用遮罩和原图仍保留。编辑中的未应用遮罩不会用于提交；任务始终冻结已应用材料，之后继续绘制不改变排队任务。结果详情可查看并恢复提交时的源图、遮罩与局部条件。

### 角色与精确参考

在侧栏添加角色，为每个角色分别编排正负提示词、文本与 Chunk，并管理启停、顺序和位置。角色也可保存到 Preset；当前实例可覆盖角色文字、启停或位置，撤销覆盖后继续使用原件。展开 Preset 会保留角色与参考内容，解除资源引用。

“角色位置”提供继承、自动和使用坐标三种集合级选择；自动定位保留已编辑坐标，继承继续采用配方或 SDK 的选择。“在画布定位”进入主区，通过角色列表或标记选择角色，再点击、拖动或使用方向键调整位置。网格与自由定位、默认位置及角色上限来自模型能力；切换模型保留编辑值，提交时由 SDK 计算实际生效位置。

精确参考可导入或选择已有图片，设置用途、强度、Fidelity、信息提取量及逐项启停。参考卡片沿用图像输入的布局，左侧图片底部集中图标操作，右侧紧凑排列参数；氛围转移原图、编码与精确参考共用这一布局，编码费用、进度与错误在卡片下方显示。原件、当前创作和实例覆盖共享这些字段，图片通过已保存媒体引用。启用且适用于当前模型和操作的精确参考会隐藏并停用本次请求的氛围转移，保留原氛围转移编辑值，解除后恢复；支持角色提示不代表支持精确参考。不支持精确参考且没有已有条目时隐藏整个分组；已有条目保留并显示不适用原因。强度和 Fidelity 保留 SDK 接受的有符号数值，不限制为 0–1。

解析和结果详情可查看角色文本、位置、本地 Token 用量，以及精确参考参数、材料和来源。问题可定位到对应角色或配方实例；提交冻结有效内容，恢复结果无需原 Chunk 或 Preset 仍存在。

### 氛围转移（Vibe Transfer）、编码与文件

在“氛围转移”组打开“材料”，选择已有原图或编码，或导入官方 `.naiv4vibe` 单文件与 `.naiv4vibebundle` 集合。文档详情列出每个条目的原图及模型、参数缓存，选定后才能追加或替换当前参考；完整文档和未选缓存继续保留。V3 使用原图参考，V4/V4.5 使用编码参考，材料类型不匹配时明确提示。SDK 判断当前模型或操作不支持氛围转移，或与精确参考冲突时，隐藏整个分组并保留编辑值，切回支持的状态后恢复显示。每项参考可启停、排序并调整有符号强度，原图还可调整信息提取量；编码强度归一化支持继承、开启和关闭。这些内容同样可保存到 Preset、建立实例覆盖或展开使用。

原图氛围转移行内显示编码按钮、预计费用及排队或执行状态。编码按源图、模型和提取参数查找已有材料，匹配时直接复用，否则由显式点击建立付费编码任务；匹配的排队或执行中任务也会复用。完成后只更新仍指向原输入的那一行；期间更换或删除该行，不会被迟到结果覆盖，编码材料仍保留供复用。

氛围转移编码作为材料保存，在参考行和材料选择中查看、复用或导出，不占用图片预览、最近图片或画廊，也没有独立的氛围转移结果标签。带有原图的材料可重新调整编码输入；只有编码而缺少原图时可继续复用，不能据此还原原图。

“材料”中的文件操作可由原图创建文档、将文档组包、导出单文件或集合、向 PNG 嵌入完整文档、读取 PNG 文档，以及提取图片中的嵌入编码。导出选定缓存的官方文件会保留源条目的全部缓存身份；缺少模型身份的原始编码可导出原始文件，不能据此补造官方文件的模型身份。

### 导演工具与 PNG 文本

“导演工具”页提供描线、草图、去背景、情绪、清理、保留对白清理和着色。每个工具独立保留源图、专有参数、校验策略与选中输出；从图片结果发送或选择另一张源图时，确认替换后仍保留该工具已编辑的参数。Prompt 按工具需要显示，低频参数默认折叠。切换页面或重启可继续编辑，不改变创作页内容。

工具使用独立估费与提交，沿用顺序队列、取消、显式重试和重启中断规则。结果区可比较输入与输出，选择全部产出、继续处理、发送回创作、用作适用参考、编码氛围转移或下载原文件；恢复工具结果只恢复对应工具的源图和参数。

在“图片元信息”的高级菜单打开“PNG 文本”，检查图片的全部文本条目，添加写入项或选择已有关键字编辑。同名关键字按 ASCII 大小写不敏感匹配并替换全部同名条目，新关键字追加，其余条目保持原样；空文本不会删除条目。写入后生成关联原图的新 PNG，保留像素和原资产，可再次检查、导出或用作底图。写入草稿及最近产出按图片保留，关闭面板或重启后重新打开可继续。

### 提交与再次使用

通过“设置 → 账户与连接”添加多个命名账户，编辑名称或更换 API Key，并选择一个账户用于后续操作。名称与选择保存在配置数据库，密钥仅保存在 Windows 凭据管理器。更换密钥建立新版本，已有任务及其重试继续使用提交时的凭据；原凭据缺失时会报错，不改用当前账户。删除账户时若仍有未完成任务会阻止，并提供查看任务的入口。密钥不进入前端持久存储、SQLite、日志或结果记录。

宿主在配置了活动账户时自动查询订阅、Anlas 余额和 V5 额度；启动、切换账户或端点、任务结束及采样过期都会触发合并采样。界面显示采样时间，失败时保留同一账户与端点上次成功的数据，并标明过期及错误，只在错误时提供重试。账户变化使估费重新计算，旧账户的迟到结果不会覆盖新账户。

当前创作通过 SDK 本地校验和估费后，点击“生成”将确定的内容加入顺序队列。“请求次数”可选 1–8，每次提交形成一个批次，每个请求有独立任务；单请求“样本数”是另一个设置，其范围随模型和计价尺寸由 SDK 决定。随机种子在各请求准备时分别确定，显式种子按用户设置保留。未取得账户采样时按非订阅条件估算；已有采样仍不代表实时余额或实际扣费承诺。提交后的内容、参数、凭据和执行设置固定，继续编辑不会改变任务。

生成参数的高级区可选择普通返回、SSE 或 MessagePack 预览，选择随当前创作保留。选中请求在同一主视图中显示等待、各样本实时预览和保存后的图片；多样本等分显示，可打开单张大图。预览保留到对应最终图片载入，查看历史或切页不会串用其他任务的帧。只显示服务提供的实际步骤；收到最终样本仍须等待完整终态与结果保存，中间帧不进入历史。

任务抽屉按批次展示请求及排队、执行、完成、失败、取消和中断状态，可查看请求、取消单个请求或批次内未完成的请求。运行中的请求可能已被服务端处理，取消不保证免扣费。失败、取消或中断后，只有显式重试才按原冻结内容和凭据建立新任务；原任务记录保留。重新打开应用不会自动续发未完成的请求。

任务详情保留 SDK 请求估算、请求终态和执行时已有的账户采样摘要。服务请求返回成功与结果保存成功分别表达；这些观察不等于实际扣费，未知费用不会显示为零。

最终图片存于数据目录的 `media/`，结果记录存于同目录的 SQLite。图片操作集中在紧凑的纯图标覆层中，名称通过提示及可访问标签提供；底部显示实际样本种子，可复制或填入参数。可下载原图、查看有效参数与来源，或恢复内容后再次生成。确认恢复后，以独立文本和有效设置替换当前创作，无需原资源仍然存在。样本种子未知时不补造；缺失或截断的图片标为不可用，不能当作完整结果打开或恢复。

## 开发入口

```sh
pnpm build:web
pnpm build:desktop
```

桌面构建生成 Windows 可执行程序，当前 CPU 版 ONNX Runtime 静态链接到程序，不生成安装包或更新包。完整检查使用 `pnpm check`，还需本机具备 Rusteward 的 `cargo-dev`、rumdl 和上述 Python 环境；安装、类型生成、词库构建及 CI 命令职责见[开发说明](docs/development.md)。
